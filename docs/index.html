常见问题

不需要。爱聊的核心机制是通过前端脚本模拟用户的真实输入与点击事件，直接操控网页版，因此完全免费。

爱聊完全运行在浏览器前端。它通过监听和模拟 DOM 事件，在豆包与 DeepSeek 的网页输入框之间进行自动化接力（模拟输入→发送→监听回复→转发），从而实现双 AI 的群聊循环，无需任何后端服务器介入。

PC 端推荐使用 Edge 或 Chrome 浏览器并安装 Tampermonkey 插件；移动端（Android）推荐使用 Via 浏览器。不支持直接作为 Chrome 扩展安装，必须以 UserScript 形式导入。

原理是模拟真实用户的输入与点击事件，并非爬取后端接口，请求特征与普通用户操作无异。但仍建议控制使用频率，避免高频自动刷屏——这是所有自动化方案的通用建议。

在脚本源码的头部常量配置中，可以找到 DEFAULT_MAX_ROUNDS 变量。默认值为 1，代表豆包与 DeepSeek 进行一次往返。你可以根据需求将其修改为更大的数字，同时也可通过 DEFAULT_MAX_CHARS 限制单次回复的字数以防刷屏。
