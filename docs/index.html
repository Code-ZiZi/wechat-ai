常见问题

需要 API Key 或付费吗？
不需要。通过模拟真实用户的输入与点击，直接操控网页版，完全免费。
我的聊天记录存在哪里？
全部保存在浏览器的本地存储（GM_setValue）中，不上传任何第三方服务器，绝对安全。
向上滑动消息列表会发生什么？
会重载当前网页。建议只在对话卡住、需要重新建立连接时使用。
