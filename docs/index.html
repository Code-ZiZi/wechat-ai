常见问题

关于原理、数据与使用边界，这里有你想知道的答案。

需要 API Key 或付费吗？
不需要。爱聊通过浏览器用户脚本，直接操控豆包与 DeepSeek 的网页版输入框，所以免 Key、免付费，也无需申请任何开发者权限。
会被封号吗？
原理是模拟真实的输入与点击事件，而不是爬取后端接口，请求特征与普通用户操作一致。但仍建议控制使用频率，避免高频自动刷屏——这是所有自动化方案的通用建议。
我的聊天记录存在哪里？
全部保存在浏览器的脚本存储（GM_setValue）中，不上传任何服务器。清空对话或在脚本管理器中卸载脚本，即彻底删除，别人无法访问。
为什么只支持豆包和 DeepSeek？
每家 AI 网页版的 DOM 结构都不同，需要单独适配输入框、发送按钮与回复解析。目前完成了这两家的适配，欢迎在 GitHub 提交 PR 增加新的 AI。
两个 AI 真的在「互相聊天」吗？
这是一种接力机制。你发言后由当前 AI 先回复，脚本再把它的回复作为上下文转交给另一个 AI，从而形成群聊感。轮数上限与字数上限可在脚本中调整。
向上滑动消息列表会发生什么？
会重载当前整个网页（包括豆包或 DeepSeek 页面本身），未发送的草稿将丢失。建议只在对话卡住、需要重新连接时使用。
