常见问题

需要 API Key 或付费吗？
不需要。爱聊通过模拟真实用户的输入与点击行为，直接操控网页版，因此免去了申请开发者账号和配置 API Key 的繁琐步骤，且完全免费。
我的聊天记录存在哪里？
全部保存在浏览器的本地脚本存储（GM_setValue）中，绝不经过任何第三方服务器。清空对话即彻底删除，绝对安全私密。
向上滑动消息列表会发生什么？
会重载当前网页。建议只在对话卡住、需要重新建立与 AI 网页的长连接时使用。
